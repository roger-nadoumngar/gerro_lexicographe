COMMENT CRÉER LE FICHIER .EXE WINDOWS DE GERRO LEXICOGRAPHE
==============================================================

Le logiciel peut être utilisé directement avec Python (voir README.md).
Pour obtenir un fichier .exe autonome (double-clic, sans Python installé),
suis ces étapes SUR UN ORDINATEUR WINDOWS.


ÉTAPE 1 — Installer Python
---------------------------
Télécharge et installe Python 3.10 ou plus récent depuis https://python.org
Pendant l'installation, coche la case "Add Python to PATH".


ÉTAPE 2 — Ouvrir une invite de commande dans le dossier du projet
-------------------------------------------------------------------
Dans l'explorateur de fichiers, ouvre le dossier qui contient app.py.
Clique dans la barre d'adresse, tape "cmd" et appuie sur Entrée.


ÉTAPE 3 — Préparer l'environnement
------------------------------------
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt pyinstaller


ÉTAPE 4 — Générer le .exe
---------------------------
    pyinstaller --noconfirm --onefile --windowed --name GerroLexicographe --add-data "lexicographe\ressources;lexicographe\ressources" app.py

Attends la fin (quelques minutes). Le fichier est créé dans le dossier
"dist" :

    dist\GerroLexicographe.exe

Le corpus d'exemple est inclus dans le .exe. Tu peux copier le .exe
n'importe où et en faire un raccourci.


DONNÉES ET SAUVEGARDE
======================
Les projets ne sont pas stockés à côté du .exe mais dans le dossier de
l'utilisateur, même si le logiciel est installé dans un dossier protégé :

    %LOCALAPPDATA%\GerroLexicographe\Projets\       les projets (.lexique)
    %LOCALAPPDATA%\GerroLexicographe\Sauvegardes\   copies automatiques

Chaque projet tient dans un seul fichier .lexique : le copier suffit pour
le sauvegarder ou le transmettre. Le menu Fichier > "Enregistrer une copie
du projet" fait une copie cohérente même pendant le travail.

Une base de l'ancienne version (lexique_ngambay.db) trouvée dans
%LOCALAPPDATA%\LexicographeNgambay\ ou à côté du logiciel est proposée à
la conversion au premier lancement. La base d'origine n'est pas modifiée.
