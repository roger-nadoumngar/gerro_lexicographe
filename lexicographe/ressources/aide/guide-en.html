1. The principle: rules, not guesses

The program never decides in the linguist's place. It applies rules that you declare (alphabet, word characters, sound classes, grammatical features…) and suggests results while showing what they are based on. Nothing enters the lexicon as “approved” without your decision.

Files you import (FLEx, Paratext, LIFT, Word…) are never modified: they are only read. Before every significant import or merge, the project is backed up automatically.

2. Getting started: create or take over a project

A project documents one language and is a single .lexique file. At start-up, choose:

  • New project: language name, ISO 639-3 code (see ethnologue.com), analysis language (French or English).
  • Import a FLEx project: the program finds the FLEx projects on the computer and takes over lexicon, texts and interlinear analyses.
  • Open an existing project.

Every new project receives SIL's list of semantic domains (1,792 domains, elicitation questions in French and English).

Then set up the project: File → Project settings.

TabTo set
Languagesnames and codes of the languages.
Writingalphabet in order (multigraphs included: a b ɓ d … ng ŋ ŋg), characters that belong to words (apostrophe, hyphen), font, sound classes for allomorphs, and the box “the corpus does not always write tones”.
Categories, Featuresgrammatical categories and features (noun class, tone…) with their allowed values.

The menu language is chosen in File → Interface language (French or English).

4. Importing data

  • Paratext project: translated books (corpus), glossary, biblical term renderings and interlinear analyses. For a parallel corpus, import the project in the documented language, then a Bible in the analysis language (“Complete Bible”).
  • Complete Bible: a folder or .zip archive in USFM or USX (for example the World English Bible or Louis Segond 1910 on eBible.org, public domain).
  • Printed dictionary: a dictionary converted to Word or text, laid out like those of the Sara-Bagirmi Project. A simulation is shown first; it completes entries and repairs truncated glosses.
  • LIFT file, Field text, Word / PDF document, Audio recording, Work from another computer (merge).

5. Working on the lexicon

  • An entry has a form, possibly a citation form and a pronunciation, a type (stem, prefix, suffix, infix…), a status (draft, to check, approved) and senses (gloss, definition, category, domains, examples).
  • Duplicates… (below the list): entries with the same form and type and at least one gloss in common; merging moves everything onto the kept entry, nothing is lost.
  • Edit the selection…: change the status, category or domain of several entries.
  • Dashboard → View and correct…: letters from another alphabet that imitate Latin letters (Cyrillic у for y…).

6. Analysing texts

Texts page: click a word. The parser suggests possible segmentations from the morphemes declared in the lexicon (prefixes, stems, suffixes, clitics, infixes, reduplication). Colours: green = approved analysis, ochre = a single suggestion, rust = several segmentations, grey = unknown.

  • If the corpus does not always write tones, tick the corresponding box in the settings: words without an exact analysis are also compared without tones, and marked “different tones: to check”.
  • An allomorph condition is written / N _ (after a nasal), / _ # (word-final), with the declared sound classes.
  • Approval page: the engine suggests a translation for each word of the parallel corpus, with the sentences that support it.

7. Collecting with speakers

  • By domain: one question at a time (“What words refer to the parts of the body?”).
  • By word list: import a Word or text list (one line or table row per word); the speaker gives the word in their language; words already known are shown.
  • Tasks: missing senses, examples, domains or pronunciations, one entry at a time.
  • Speaker mode: full screen, large characters.

Collected words are drafts, to check afterwards in the Lexicon.

8. Preparing a primer

Primer page: the program counts the graphemes of the corpus and suggests a teaching order (at each lesson, the letter that makes the most new words readable). You can reorder. Export as a PDF booklet or for Bloom's “Decodable Reader” tool.

10. Data, backups, working on several computers

  • Projects: %LOCALAPPDATA%\GerroLexicographe\Projets; automatic backups: the Sauvegardes folder next to it (File menu → Open the backups folder).
  • File → Save a copy of the project makes a consistent copy, even while you work.
  • Several computers: copy the project to the other computer, work there, then Imports → Work from another computer: new entries are added; for an entry changed on both sides, the most recent version wins.

11. Frequent questions

A word with an apostrophe is split in two (“dee’g”).

Add the apostrophe to the word characters: Settings → Writing.

The lexicon does not follow the order of my alphabet.

Declare the alphabet in order, multigraphs included, in Settings → Writing.

Many corpus words are “unknown”.

Check that the lexicon and the corpus use the same spelling; if the corpus does not write tones, tick “the corpus does not always write tones”. Analyse the most frequent words first (Word forms page).

The Android app does not build.

Open Dictionary App Builder once so that it installs Java and the Android SDK; check the keystore and its password. DAB's log is shown if the build fails.
