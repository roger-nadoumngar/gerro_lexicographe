1. Le principe : des règles, pas de devinettes

Le logiciel ne décide jamais à la place du linguiste. Il applique des règles que vous déclarez (alphabet, caractères des mots, classes de sons, traits grammaticaux…) et vous propose des résultats en montrant sur quoi ils reposent. Rien n'entre dans le lexique comme « validé » sans votre décision.

Les fichiers que vous importez (FLEx, Paratext, LIFT, Word…) ne sont jamais modifiés : ils sont seulement lus. Avant chaque import ou fusion importante, le projet est sauvegardé automatiquement.

2. Démarrer : créer ou reprendre un projet

Un projet documente une langue et tient dans un seul fichier .lexique. Au lancement, choisissez :

  • Nouveau projet : nom de la langue, code ISO 639-3 (par exemple sba pour le ngambay, voir ethnologue.com), langue d'analyse (français ou anglais).
  • Importer un projet FLEx : le logiciel trouve les projets FLEx de l'ordinateur et reprend lexique, textes et analyses interlinéaires.
  • Ouvrir un projet existant.

Chaque nouveau projet reçoit la liste des domaines sémantiques de SIL (1 792 domaines, questions de collecte en français et en anglais).

Réglez ensuite le projet : Fichier → Réglages du projet.

OngletÀ régler
Languesnoms et codes des langues.
Écriturealphabet dans l'ordre (multigraphes compris : a b ɓ d … ng ŋ ŋg), caractères qui font partie des mots (apostrophe, tiret), police, classes de sons pour les allomorphes, et la case « le corpus n'écrit pas toujours les tons ».
Catégories, Traitscatégories grammaticales et traits (classe nominale, ton…) avec leurs valeurs permises.

La langue des menus se choisit dans Fichier → Langue de l'interface (français ou anglais).

4. Importer des données

Page Imports :

  • Projet Paratext : livres traduits (corpus), glossaire, rendus des termes bibliques et analyses de l'interlinéaire. Pour un corpus parallèle, importez le projet dans la langue documentée, puis une Bible dans la langue d'analyse (« Bible complète »).
  • Bible complète : un dossier ou une archive .zip en USFM ou USX (par exemple Louis Segond 1910 sur eBible.org, domaine public).
  • Dictionnaire imprimé : un dictionnaire converti en Word ou en texte, présenté comme ceux du Projet Sara-Baguirmi. Une simulation est montrée avant l'import ; il complète les entrées et répare les gloses coupées.
  • Fichier LIFT, Texte de terrain, Document Word / PDF, Enregistrement audio, Travail d'un autre poste (fusion).

5. Travailler le lexique

  • Une entrée a une forme, éventuellement une forme de citation et une prononciation, un type (radical, préfixe, suffixe, infixe…), un statut (brouillon, à vérifier, validé) et des sens (glose, définition, catégorie, domaines, exemples).
  • Doublons… (en bas de la liste) : entrées de même forme et de même type avec au moins une glose commune ; la fusion reporte tout sur l'entrée gardée, rien n'est perdu.
  • Modifier la sélection… : changer le statut, la catégorie ou le domaine de plusieurs entrées.
  • Tableau de bord → Voir et corriger… : lettres d'un autre alphabet qui imitent des lettres latines (у cyrillique pour y…).

6. Analyser les textes

Page Textes : cliquez sur un mot. L'analyseur propose les découpes possibles à partir des morphèmes déclarés au lexique (préfixes, radicaux, suffixes, clitiques, infixes, redoublement). Couleurs : vert = analyse validée, ocre = une seule proposition, rouille = plusieurs découpes, gris = inconnu.

  • Si le corpus n'écrit pas toujours les tons, cochez la case correspondante dans les réglages : les mots sans analyse exacte sont aussi comparés sans les tons, et marqués « tons différents : à vérifier ».
  • Une condition d'allomorphe s'écrit / N _ (après une nasale), / _ # (en fin de mot), avec les classes de sons déclarées.
  • Page Validation : le moteur propose une traduction pour chaque mot du corpus parallèle, avec les phrases qui la justifient.

7. Collecter avec des locuteurs

  • Par domaine : une question à la fois (« Quels mots désignent les parties du corps ? »).
  • Par liste de mots : importez une liste Word ou texte (une ligne ou une rangée de tableau par mot) ; le locuteur donne le mot dans sa langue ; les mots déjà connus sont montrés.
  • Tâches : sens, exemples, domaines ou prononciations manquants, une entrée à la fois.
  • Mode locuteur : plein écran, gros caractères.

Les mots collectés sont des brouillons, à vérifier ensuite dans le Lexique.

8. Préparer un syllabaire

Page Syllabaire : le logiciel compte les graphèmes du corpus et propose un ordre d'enseignement (à chaque leçon, la lettre qui rend lisibles le plus de nouveaux mots). Vous pouvez réordonner. Export en livret PDF ou pour l'outil « Decodable Reader » de Bloom.

Seules les entrées des statuts choisis sont publiées (par défaut : à vérifier et validé, pas les brouillons).

10. Données, sauvegardes, travail à plusieurs

  • Projets : %LOCALAPPDATA%\GerroLexicographe\Projets ; sauvegardes automatiques : dossier Sauvegardes à côté (menu Fichier → Ouvrir le dossier des sauvegardes).
  • Fichier → Enregistrer une copie du projet fait une copie cohérente, même pendant le travail.
  • Plusieurs ordinateurs : copiez le projet sur l'autre poste, travaillez, puis Imports → Travail d'un autre poste : les nouvelles entrées sont ajoutées ; pour une entrée modifiée des deux côtés, la version la plus récente l'emporte.

11. Questions fréquentes

Un mot avec apostrophe est coupé en deux (« dee’g »).

Ajoutez l'apostrophe aux caractères des mots : Réglages → Écriture.

Le lexique ne suit pas l'ordre de mon alphabet.

Déclarez l'alphabet dans l'ordre, multigraphes compris, dans Réglages → Écriture.

Beaucoup de mots du corpus sont « inconnus ».

Vérifiez que le lexique et le corpus suivent la même orthographe ; si le corpus n'écrit pas les tons, cochez « le corpus n'écrit pas toujours les tons ». Analysez d'abord les mots les plus fréquents (page Formes de mots).

L'application Android ne se construit pas.

Ouvrez une fois Dictionary App Builder pour qu'il installe Java et le SDK Android ; vérifiez le keystore et son mot de passe. Le journal de DAB s'affiche en cas d'échec.
